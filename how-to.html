How to Use

Quick guide to reporting civic issues in Bengaluru via WhatsApp

Reporting a Civic Issue

  1. Open Civic Issues from the home page
  2. Add a photo — Take photo if you are on site, or Choose photo from gallery
  3. Confirm the photo clearly shows the issue
  4. Set location on the map — search an address, tap the map, drag the pin, or use Use my current location
  5. Select issue category and add details
  6. Review ward, corporation, and constituency, then tap Send via WhatsApp
  7. WhatsApp opens with a pre-filled message — review and send

Location tips

  • Gallery photos on mobile often arrive without GPS — you will need to set the pin on the map
  • Camera capture on site can use your phone's current location (check the blue accuracy circle and drag the pin if needed)
  • Reports must be within Greater Bengaluru Authority (GBA) limits
  • Nothing is uploaded to our servers — the report goes via WhatsApp

Using the Map

If your photo has no GPS or the pin looks wrong:

  1. Go to the Location step after choosing your photo
  2. Use the search bar above the map to find a place
  3. Tap the map to drop the pin, or drag it to the exact spot
  4. When using live GPS, a light blue circle shows approximate accuracy — adjust the pin if needed
  5. Check the box confirming the pin matches where the photo was taken

Need Help?

  • Make sure the pin is inside Bengaluru / GBA boundaries
  • Enable location permission if you use "Use my current location"
  • Select an issue category before sending
