English
ನಾಗರಿಕ ಧ್ವನಿ ಗೌಪ್ಯತಾ ನೀತಿ

ಗೌಪ್ಯತಾ ನೀತಿ ಮತ್ತು ಸೇವಾ ಶರತುಗಳು

ಕೊನೆಯ ನವೀಕರಣ: ಏಪ್ರಿಲ್ 2026

📋 ಸಂಕ್ಷಿಪ್ತ ವಿವರಣೆ

ನಾಗರಿಕ ಧ್ವನಿ ಬೆಂಗಳೂರು ನಾಗರಿಕರಿಗೆ X (ಪೂರ್ವತನ ಟ್ವಿಟರ್) ಮೂಲಕ ಅಧಿಕಾರಿಗಳಿಗೆ ನೇರವಾಗಿ ನಾಗರಿಕ ಸಮಸ್ಯೆಗಳನ್ನು ವರದಿ ಮಾಡಲು ಅನುಮತಿಸುವ ಮಂಚವಾಗಿದೆ.

🔒 ಡೇಟಾ ಗೌಪ್ಯತೆ

ನಾವು ನಿಮ್ಮ ಡೇಟಾ ಅನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ

  • ಬಳಕೆದಾರ ಡೇಟಾ ಸಂಗ್ರಹಣೆ ಇಲ್ಲ: ನಾವು ಯಾವುದೇ ವೈಯಕ್ತಿಕ ಮಾಹಿತಿ, ಬಳಕೆದಾರ ಖಾತೆಗಳು, ಅಥವಾ ಗುರುತಿಸಬಹುದಾದ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ, ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ ಅಥವಾ ಉಳಿಸಿಕೊಳ್ಳುವುದಿಲ್ಲ.
  • ಚಿತ್ರ ಸಂಗ್ರಹಣೆ ಇಲ್ಲ: ನೀವು ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಫೋಟೋಗಳನ್ನು ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ನೇರವಾಗಿ X ಗೆ ಪೋಸ್ಟ್ ಮಾಡಲಾಗುತ್ತದೆ. ನಾವು ನಮ್ಮ ಸರ್ವರ್‌ಗಳಲ್ಲಿ ಚಿತ್ರಗಳನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ.
  • ಸ್ಥಳ ಟ್ರ್ಯಾಕಿಂಗ್ ಇಲ್ಲ: GPS ನಿರ್ದೇಶಾಂಕಗಳನ್ನು ನಿಮ್ಮ ಫೋಟೋಗಳಿಂದ ಹೊರತೆಗೆಯಲಾಗುತ್ತದೆ ಅಥವಾ ನಕ್ಷೆಯಲ್ಲಿ ಆಯ್ಕೆ ಮಾಡಲಾಗುತ್ತದೆ, ವರದಿಗಾಗಿ ಮಾತ್ರ ಬಳಸಲಾಗುತ್ತದೆ, ಮತ್ತು ನಮ್ಮಿಂದ ಸಂಗ್ರಹಿಸಲಾಗುವುದಿಲ್ಲ.
  • AI ಪ್ರಕ್ರಿಯೆ: ಪ್ರಸರಣದ ಮೊದಲು ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಚಿತ್ರಗಳನ್ನು ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಲಾಗುತ್ತದೆ. ದುರುಪಯೋಗವನ್ನು ತಡೆಗಟ್ಟಲು ಚಿತ್ರಗಳನ್ನು AWS Rekognition ಗೆ ವಿಷಯ ಮಾಡರೇಶನ್ ಗಾಗಿ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. ಅಪಮಾನಕರ ಭಾಷೆಯನ್ನು ತಡೆಗಟ್ಟಲು ಪಠ್ಯ ವಿವರಣೆಗಳನ್ನು AWS Comprehend ಬಳಸಿ ವಿಶ್ಲೇಷಿಸಲಾಗುತ್ತದೆ. ಈ AWS ಸೇವೆಗಳು ಮಾಡರೇಶನ್ ಉದ್ದೇಶಗಳಿಗಾಗಿ ಮಾತ್ರ ಡೇಟಾವನ್ನು ತಾತ್ಕಾಲಿಕವಾಗಿ ಪ್ರಕ್ರಿಯೆಗೊಳಿಸುತ್ತವೆ ಮತ್ತು ನಿಮ್ಮ ವಿಷಯವನ್ನು ಉಳಿಸಿಕೊಳ್ಳುವುದಿಲ್ಲ.

📸 ಸಾರ್ವಜನಿಕ ಪೋಸ್ಟಿಂಗ್

ಮಹತ್ವಪೂರ್ಣ: ನೀವು ವರದಿಯನ್ನು ಸಲ್ಲಿಸಿದಾಗ:

  • ನಿಮ್ಮ ಚಿತ್ರ ಮತ್ತು ಸ್ಥಳದ ವಿವರಗಳನ್ನು X ನಲ್ಲಿ ಸಾರ್ವಜನಿಕವಾಗಿ ಪೋಸ್ಟ್ ಮಾಡಲಾಗುತ್ತದೆ (ಪೂರ್ವತನ ಟ್ವಿಟರ್)
  • ಪೋಸ್ಟ್ ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿ ಯಾರಿಗಾದರೂ ಪ್ರವೇಶಿಸಬಹುದಾಗಿದೆ
  • ಪೋಸ್ಟ್‌ಗಳನ್ನು ಸಂಬಂಧಿತ ಅಧಿಕಾರಿಗಳೊಂದಿಗೆ ಟ್ಯಾಗ್ ಮಾಡಲಾಗುತ್ತದೆ (@zenc_civic)
  • ಒಮ್ಮೆ ಪೋಸ್ಟ್ ಮಾಡಿದ ನಂತರ, ವಿಷಯವು X ನ ನಿಯಮಗಳು ಮತ್ತು ಗೌಪ್ಯತಾ ನೀತಿಯಿಂದ ನಿಯಂತ್ರಿಸಲ್ಪಡುತ್ತದೆ

🍪 ಕುಕೀಗಳು ಮತ್ತು ಸ್ಥಳೀಯ ಸಂಗ್ರಹಣೆ

ನಾವು ಬ್ರೌಸರ್ ಸ್ಥಳೀಯ ಸಂಗ್ರಹಣೆಯನ್ನು ಮಾತ್ರ ಬಳಸುತ್ತೇವೆ:

  • ಥೀಮ್ ಆದ್ಯತೆ (ಬೆಳಕು/ಕತ್ತಲೆ ಮೋಡ್)
  • ಭಾಷಾ ಆದ್ಯತೆ (ಇಂಗ್ಲಿಷ್/ಕನ್ನಡ)

ಯಾವುದೇ ಟ್ರ್ಯಾಕಿಂಗ್ ಕುಕೀಗಳು ಅಥವಾ ವಿಶ್ಲೇಷಣೆಗಳನ್ನು ಬಳಸಲಾಗುವುದಿಲ್ಲ.

✅ ಬಳಕೆದಾರ ಒಪ್ಪಿಗೆ

ನಾಗರಿಕ ಧ್ವನಿ ಅನ್ನು ಬಳಸುವುದರಿಂದ, ನೀವು ಅಂಗೀಕರಿಸುತ್ತೀರಿ ಮತ್ತು ಒಪ್ಪುತ್ತೀರಿ:

  • ನೀವು ಸಲ್ಲಿಸುವ ಚಿತ್ರಗಳು ಮತ್ತು ಸ್ಥಳ ಡೇಟಾವನ್ನು X ನಲ್ಲಿ ಸಾರ್ವಜನಿಕವಾಗಿ ಪೋಸ್ಟ್ ಮಾಡಲಾಗುವುದು
  • ವರದಿ ಮಾಡಿದ ಸಮಸ್ಯೆಯನ್ನು ಛಾಯಾಚಿತ್ರಿಸಲು ಮತ್ತು ಹಂಚಿಕೊಳ್ಳಲು ನಿಮಗೆ ಹಕ್ಕಿದೆ
  • ನೀವು ಸೂಕ್ಷ್ಮ ವೈಯಕ್ತಿಕ ಮಾಹಿತಿಯನ್ನು ಒಳಗೊಂಡಿರುವ ಚಿತ್ರಗಳನ್ನು ಪೋಸ್ಟ್ ಮಾಡುವುದಿಲ್ಲ
  • ನೀವು ಪೋಸ್ಟ್ ಮಾಡುವ ವಿಷಯಕ್ಕೆ ನೀವು ಜವಾಬ್ದಾರರಾಗಿರುತ್ತೀರಿ

🛡️ ಭದ್ರತೆ

  • ಎಲ್ಲಾ ಸಂಪರ್ಕಗಳು HTTPS ಎನ್‌ಕ್ರಿಪ್ಷನ್ ಬಳಸುತ್ತವೆ
  • ಚಿತ್ರ ಸಂಕೋಚನ ಮತ್ತು ಮುಖ ಪತ್ತೆಹಚ್ಚುವಿಕೆ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ನಡೆಯುತ್ತದೆ
  • X ಗೆ API ಕರೆಗಳನ್ನು ನಮ್ಮ ಗೇಟ್‌ವೇ ಮೂಲಕ ಸುರಕ್ಷಿತವಾಗಿ ಮಾಡಲಾಗುತ್ತದೆ

⚖️ ಹೊಣೆಗಾರಿಕೆ

ನಾಗರಿಕ ಧ್ವನಿ "ಇದ್ದಂತೆಯೇ" ಖಾತರಿಗಳಿಲ್ಲದೆ ಒದಗಿಸಲಾಗಿದೆ. ನಾವು ಇವುಗಳಿಗೆ ಜವಾಬ್ದಾರರಲ್ಲ:

  • ಅಧಿಕಾರಿಗಳು ತೆಗೆದುಕೊಂಡ ಪ್ರತಿಕ್ರಿಯೆ ಸಮಯಗಳು ಅಥವಾ ಕ್ರಮಗಳು
  • ಬಳಕೆದಾರರು ಪೋಸ್ಟ್ ಮಾಡಿದ ವಿಷಯ
  • ಮೂರನೇ-ವ್ಯಕ್ತಿ ಸೇವೆಗಳು (X ಪ್ಲಾಟ್‌ಫಾರ್ಮ್, ನಕ್ಷೆ ಒದಗಿಸುವವರು)
